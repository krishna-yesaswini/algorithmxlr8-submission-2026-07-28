# Maximum Product Subarray

**Difficulty:** `Medium`

## Problem

Given an integer array nums, find a contiguous subarray that has the largest product, and return that product.

Read n on the first line of standard input, then n space-separated integers on the second line. Print the maximum product to standard output.

## Examples

### Example 1

**Input**
```
4
2 3 -2 4
```
**Output**
```
6
```

**Explanation:** The subarray [2, 3] has the largest product, 6.

### Example 2

**Input**
```
3
-2 0 -1
```
**Output**
```
0
```

**Explanation:** The 0 blocks any subarray from spanning across it, so the best achievable product is 0 itself.
