# Sliding Window Maximum

**Difficulty:** `Hard`

## Problem

Given an integer array nums and an integer k, there is a sliding window of size k that moves from the very left of the array to the very right, one position at a time. Return the maximum value in the window at each position.

Read n and k on the first line of standard input, then n space-separated integers on the second line. Print the maximum of each window, space-separated, to standard output.

## Examples

### Example 1

**Input**
```
8 3
1 3 -1 -3 5 3 6 7
```
**Output**
```
3 3 5 5 6 7
```

**Explanation:** Each window of 3 consecutive elements, and its maximum, slides one step at a time across the array.

### Example 2

**Input**
```
1 1
1
```
**Output**
```
1
```

**Explanation:** A window the same size as the array itself has only one position, and its maximum is the single element.
