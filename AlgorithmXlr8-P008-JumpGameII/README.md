# Jump Game II

**Difficulty:** `Hard`

## Problem

Given an array of non-negative integers nums, you start at index 0. Each element nums[i] represents the maximum jump length from that position.

Return the minimum number of jumps needed to reach the last index. You are guaranteed it is always possible to reach the last index.

Read n on the first line of standard input, then n space-separated integers on the second line. Print the minimum number of jumps to standard output.

## Examples

### Example 1

**Input**
```
5
2 3 1 1 4
```
**Output**
```
2
```

**Explanation:** Jump from index 0 to index 1 (length 1), then from index 1 to index 4 (length 3), reaching the end in 2 jumps.

### Example 2

**Input**
```
5
2 3 0 1 4
```
**Output**
```
2
```

**Explanation:** The same 2-jump strategy works even though index 2 alone would be a dead end.
