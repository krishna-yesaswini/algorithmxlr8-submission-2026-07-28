# Missing Number

**Difficulty:** `Easy`

## Problem

Given an array nums containing n distinct numbers taken from the range [0, n], return the one number in that range that is missing from the array.

Read n on the first line of standard input, then n space-separated integers on the second line. Print the missing number to standard output.

## Examples

### Example 1

**Input**
```
3
3 0 1
```
**Output**
```
2
```

**Explanation:** The range [0, 3] should contain 0, 1, 2, 3; only 2 is missing.

### Example 2

**Input**
```
2
0 1
```
**Output**
```
2
```

**Explanation:** The range [0, 2] should contain 0, 1, 2; only 2 is missing.

### Example 3

**Input**
```
9
9 6 4 2 3 5 7 0 1
```
**Output**
```
8
```

**Explanation:** The range [0, 9] should contain every value from 0 to 9; only 8 is missing.
